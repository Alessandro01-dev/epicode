# EPICODE - Web Development Master

This repository contains my exercises, daily practices, and core projects completed during the Epicode Web Development Master program (Part-Time). The course goes from basic web design to advanced JavaScript, React applications, and full-stack backend integrations.

---

### 📂 Repository Roadmap

- **[Pre-corso](./Pre-corso)**
  - _Core Topics:_ Basic HTML structures, introductory CSS styling, and first browser steps.
  - _Deliverables:_ Simple static pages, registration forms, and a basic **YouTube Clone** simulation.

- **[M1 - Intro to Web Development](./M1)**
  - _Core Topics:_ Structuring layouts using semantic HTML5 and basic CSS3 styling.
  - _Deliverables:_ Layout practice files (`W1D1` to `W2D4`) focusing on page building blocks.

- **[M2 - Programming Foundations (JavaScript Basics)](./M2)**
  - _Core Topics:_ JavaScript logic (variables, functions, loops, conditions) and basic DOM manipulation.
  - _Deliverables:_
    - `W4D4 calculator`: A working web-based calculator built with vanilla JavaScript.
    - **`W5BW1` (Build Week 1 - Benchmark Quiz):** An interactive, timed multiple-choice quiz application with a score calculator.

- **[M3 - Web Design & Frameworks](./M3)**
  - _Core Topics:_ Responsive layouts, CSS Flexbox, Media Queries, and the **Bootstrap** framework.
  - _Deliverables:_
    - `W2D4` / `W4D1`: Dynamic layouts for browsing travel destinations and movie lists.
    - **`W5BW2` (Build Week 2 - Airbnb Clone):** A multi-page responsive website replicating the Airbnb layout and interfaces.

- **[M4 - JavaScript Advanced (Async & APIs)](./M4)**
  - _Core Topics:_ Asynchronous JavaScript (Promises, Async/Await), fetching external API data, and building dynamic CRUD interfaces.
  - _Deliverables:_
    - `W4D1`: An E-commerce product manager panel with full Add/Edit product functions.
    - **`W5BW3` (Build Week 3 - Spotify Clone):** A music streaming replica interface featuring functional Home, Album, and Artist pages fetching real media data.

- **[M5 - Intro to React](./M5)**
  - _Core Topics:_ Component-based architecture with React, managing application states, props, hooks (`useState`, `useEffect`), and Vite build setups.
  - _Deliverables:_ **`W5BW4` (Build Week 4 - React Platform App):** A fully production-ready frontend web application built entirely with React components.

- **[M6 - Node, Express & MongoDB](./M6)**
  - _Core Topics:_ Building RESTful APIs with Node.js and Express, database object modeling with MongoDB/Mongoose, and cloud deployment environments.
  - _Deliverables:_
    - `Strive blog`: A complete Full-Stack blogging architecture connecting a React interface to an Express API backend (configured for Vercel deployment).
    - **`W5BW5` (Build Week 5 - Full-Stack App):** A complete module project divided into independent `frontend` and `backend` workspaces.
